# Business Solutions System — General Shop Management System

A modern, mobile-friendly multi-device shop management system configured for Supabase.

## Included
- Owner-configurable shop name
- Supabase authentication
- Shared cloud data
- Dashboard
- Products and stock
- Decimal quantities for loose goods (e.g. 0.125 kg)
- Divided/bulk product stock types
- Sales/POS
- Expenses
- Customers and suppliers placeholders
- Reports
- Bright responsive UI

## Setup
1. Open `supabase_schema.sql` in Supabase SQL Editor and run it.
2. Host `index.html` on GitHub Pages, Netlify, Vercel, or another static host.
3. The supplied Supabase project URL and publishable key are already configured in `index.html`.
4. Create the first account from the login screen.
